# Поиск: Яндекс Вебмастер, Метрика, ИИ-поиск

Что уже сделано в коде и что нужно сделать руками, когда появятся домен и хостинг.

## Что сайт отдаёт сам

| Адрес | Что это |
|---|---|
| `/robots.txt` | Правила из админки («SEO по умолчанию» → robots.txt) + разрешение ИИ-ботам + `Clean-param` для UTM-меток + ссылка на карту сайта |
| `/sitemap.xml` | Все страницы, проекты и услуги из админки, обновляется сама |
| `/llms.txt` | Выжимка сайта для ИИ-ассистентов (услуги, прайс, вопросы-ответы, проекты) |
| `<meta name="yandex-verification">` | Код подтверждения Вебмастера |
| JSON-LD на страницах | Организация (ProfessionalService), услуги с ценами, прайс (OfferCatalog), проекты (CreativeWork), FAQ, хлебные крошки |
| `<link rel="canonical">` | На всех публичных страницах |

## Переменные окружения на хостинге

```
NEXT_PUBLIC_SERVER_URL=https://домен.ru   # без слеша в конце; от него строятся canonical, sitemap, разметка
YANDEX_VERIFICATION=                      # можно вместо поля в админке
NEXT_PUBLIC_YANDEX_METRIKA_ID=            # можно вместо поля в админке
SITE_NOINDEX=1                            # только на тестовом адресе: закрывает сайт от поиска
```

## Чек-лист после покупки домена

1. На хостинге задать `NEXT_PUBLIC_SERVER_URL=https://домен.ru`, включить HTTPS и редирект с `www` и `http` на один основной адрес.
2. Яндекс Метрика: metrika.yandex.ru → «Добавить счётчик», адрес сайта, вебвизор **не включать** (см. ниже). Номер счётчика вписать в админке: «Настройки» → «Интеграции» → «Номер счётчика Яндекс Метрики».
3. В Метрике создать цели типа «JavaScript-событие»: `lead` (любая заявка), `lead_quiz`, `lead_excursion`.
4. Яндекс Вебмастер: webmaster.yandex.ru → «Добавить сайт» → способ «Мета-тег». Из тега `<meta name="yandex-verification" content="abc123">` скопировать только `abc123` в админку: «Настройки» → «SEO по умолчанию» → «Код Яндекс Вебмастера». Нажать «Проверить».
5. В Вебмастере: «Индексирование» → «Файлы Sitemap» → добавить `https://домен.ru/sitemap.xml`.
6. «Настройки» → «Привязка к Метрике» → выбрать счётчик.
7. «Информация о сайте» → «Регион» → Москва (и второй город, если есть офис).
8. Проверить разметку: «Инструменты» → «Валидатор микроразметки», вставить адреса главной, услуги, проекта.
9. Добавить организацию в Яндекс Бизнес (карточка на Картах) с тем же адресом и телефоном, что в админке.
10. Заполнить в админке «Контакты и реквизиты» → «Реквизиты оператора персональных данных»: они попадут в политику, согласие и разметку.

## ИИ-поиск

- В `robots.txt` открыт доступ ботам Яндекса (в т. ч. `YandexAdditional` — нейроответы), GPTBot/OAI-SearchBot (ChatGPT), ClaudeBot, PerplexityBot, Google-Extended, Applebot-Extended.
- Все страницы рендерятся на сервере: текст виден ботам без JavaScript.
- `/llms.txt` даёт короткую сводку на Markdown со ссылками.
- Чем больше на страницах услуг текста с конкретикой (сроки, состав работ, цены, вопросы-ответы), тем чаще ИИ будет цитировать сайт. Вопросы-ответы заполняются в админке у каждой услуги.

## Персональные данные

- Вебвизор в Метрике выключен в коде: он записывает ввод в формы (телефоны), а это персональные данные.
- В политике заявки уходят в Битрикс24 (серверы в РФ), трансграничной передачи нет. Уведомления о заявках в Telegram (TELEGRAM_BOT_TOKEN) на проде не включать: это передача за границу, понадобится уведомление в Роскомнадзор и правка политики.
- До запуска подать уведомление об обработке ПД в Роскомнадзор (pd.rkn.gov.ru), если оператор ещё не в реестре.
- Тексты `/politika` и `/soglasie` — шаблон под 152-ФЗ, перед запуском их стоит показать юристу. При правке текста поменять `LEGAL_VERSION` в `src/lib/site/legal.ts`: дата редакции сохраняется в каждой заявке.
